# 一建每日刷题

免费、离线可用的一级建造师刷题工具。每天 10 题，答完自动打卡；错题按知识点换题复习，直到掌握。

**打开使用：<https://zuozhao618-byte.github.io/yijian/>**

## 安装

- **iPhone**：用 Safari 打开 → 分享 → 添加到主屏幕。之后固定从桌面图标打开。
- **安卓 / 电脑**：用 Chrome 或 Edge 打开 → 添加到主屏幕 / 安装。

装好后没网也能用，联网打开会自动更新题库。

## 功能

每日任务与连续打卡 · 错题间隔复习 · 难度递进 · 多选题按考试规则判分 · 题目解析 · 错题本 · 专项练习 · 学习统计 · 考试倒计时

## 注意

- 做题记录只存在本机。换手机前请在「设置」里复制备份，粘贴到备忘录。
- 题目按考点原创编写，不是真题原题，以官方教材和现行法规为准。
- 发现错题请提交 [Issue](https://github.com/zuozhao618-byte/yijian/issues)，写上题号（如 `fg031`）。
- 有什么建议或者意见欢迎朋友们留言，我会考虑并改进。
